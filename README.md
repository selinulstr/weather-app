🌦️ Weather Forecast Application
A beautiful, responsive weather app built with Node.js and OpenWeatherMap API

https://imgur.com/i57sUGo
https://imgur.com/a/CQtc4Pc

✨ Features
Feature	Description
🔍 City Search	Find weather for any city worldwide
🌡️ Real-time Data	Current temperature and conditions
📊 Detailed Metrics	Humidity, wind speed, pressure and more
🎨 Dynamic UI	Background changes with weather conditions
⏰ Local Time	Accurate date/time for each location
📱 Responsive Design	Works on all device sizes
